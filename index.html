Mealy ⇄ Moore Converter

Define a machine, convert it, follow each conversion step, then run both machines on the same input.

1Concepts

Both are finite-state machines with output, written as (Q, Σ, Δ, δ, λ, q₀). They differ only in where the output comes from.

Mealy machine

Output depends on the state and the input: λ : Q × Σ → Δ.

The output is written on the transition, as a / z.

Input of length n gives output of length n.

Moore machine

Output depends on the state only: λ : Q → Δ.

The output is written inside the state, as q / z.

Input of length n gives output of length n + 1, because the start state emits an output before any input is read.

Conversion rules

Mealy → Moore: split every state that is entered with different outputs into one copy per output. The result has at most |Q| · |Δ| states.

Moore → Mealy: keep the same states and set λ′(q, a) = λ(δ(q, a)), so each transition carries the output of the state it enters.
